# AI Usage Disclosure

Check First was built by Viraj Mutti with help from an AI coding assistant
(**Claude Code**, Anthropic). The contest allows AI use if it is fully
disclosed, so this file records what the AI generated and what Viraj wrote.
It's updated as the project goes.

The app itself also *uses* AI at runtime: the server route calls Claude
(`claude-sonnet-5-5` by default) or, if only a Gemini key is set, Google Gemini
(`gemini-3.5-flash-lite`) to analyze messages. That is part of the
product, separate from how the code was written.

## Design decisions made with AI help

- **Two detection layers.** Rules run offline in the browser; AI runs on the server. Final risk = the higher of the two.
- **8 second AI timeout.** If the AI is slow, fails, or isn't configured, the app still shows the rules result with a notice, never a blank screen.
- **No database.** Messages are never stored or logged.
- **Chinese font.** The phone's built-in CJK font is used (Noto Sans CJK on Android, PingFang on iPhone). Self-hosting the Chinese font made builds fail on slow networks.
